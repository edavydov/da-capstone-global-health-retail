# Governance

Owner:
- Name: Data Product Owner (example: Alice Example)
- Responsibilities: accountable for the product outcomes, prioritization, and business decisions.

Steward:
- Name: Data Steward (example: Bob Steward)
- Responsibilities: operational data quality, metadata management, access oversight, policy enforcement.

Custodian:
- Name: Data Custodian (example: Carla Custodian)
- Responsibilities: technical operations, pipelines, backups, and system-level security/configuration.

Access & Approval:
- Sensitive data access requires documented approval from Owner and Steward, recorded in the access request log.
- All schema changes must go through the change control board and be documented in /documentation/changes.md (not included here).
